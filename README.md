# Performance-Optimized Corporate Landing Page

A high-performance, responsive corporate landing page built with **HTML5**, **Tailwind CSS**, and **JavaScript**. This project is specifically engineered for maximum speed, accessibility, and SEO efficiency.

## Performance Metrics (Lighthouse Audit)
- **Performance:** 98-100/100
- **Accessibility:** 100/100
- **Best Practices:** 100/100
- **SEO:** 100/100

## Key Features & Optimizations
- **Frontend Speed Optimization:** Implemented asset minification and critical CSS delivery to minimize render-blocking execution times.
- **Image Optimization:** Utilized high-resolution images with **Lazy Loading** and modern formatting to improve Core Web Vitals (LCP & CLS).
- **Tailwind Utility First:** Compiled an ultra-lightweight style framework using Tailwind CLI for optimized production builds.
- **Responsive Design:** Fully fluid layout across all viewports (Mobile, Tablet, Desktop).
- **Semantic HTML5:** Built with SEO and accessibility (A11y) best practices.

## Tech Stack
- **Styling:** Tailwind CSS (via PostCSS)
- **Icons:** Lucide Icons / SVG
- **Deployment:** Vercel
- **Version Control:** Git & GitHub

## Installation & Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/USERNAME_ANDA/corporate-landing-page.git
   cd corporate-landing-page
   
2. **Install dependencies:**
   ```bash
   npm install

3. **Start Tailwind Watcher (Development) :**
    ```bash
    npm run watch

4. **Build for Production:**
    ```bash
    npm run build

## Deployment


This project is automatically deployed via Vercel integration with GitHub. Every push to the main branch triggers a production-optimized build.
